# Test Data Analyzer & Automatic Report Generator

Turns a raw measurement log from an endurance or durability test into a **finished Excel + PDF report in seconds**,
with anomalies detected and highlighted automatically.

![Report preview](docs/report_preview.png)

## What it detects

| Check | How | Why it matters |
|---|---|---|
| **Limit violations** | Every value vs its spec limits | Hard failures |
| **Spikes** | Distance from the local (rolling) median, in robust std-devs | Catches abnormal cycles that are still *inside* the limits |
| **Drift** | 50-cycle rolling average vs the start-of-test baseline | **Early warning**: in the demo, drift is flagged at cycle 410, 90 cycles before the limit is broken at cycle 500 |
| **Data gaps** | Missing cycle numbers | Logger dropouts are reported, not hidden |

## Output

- **`test_report.pdf`**: verdict (PASS / WARNING / FAIL), KPIs, a findings table sorted by severity, and trend charts with limits, anomalies and drift markers
- **`test_report.xlsx`**: Summary, Anomalies, full Data (out-of-limit cells in red), and **native Excel charts** the client can still edit
- **`chart_*.png`**: charts ready to paste into presentations

## Run it

```bash
pip install pandas numpy matplotlib openpyxl reportlab
python make_sample_data.py          # synthetic 500-cycle test log with injected faults
python generate_report.py sample_data/endurance_test_log.csv -o output
```


## Adapting it

All signals, units, spec limits and drift thresholds are in one `SIGNALS` table at the top of `generate_report.py`.
Any CSV with a `cycle` and `timestamp` column plus measured values works: test benches, production lines,
sensors or machine logs.

## Tech
